## 1. 재생 단위 (CLAUDE.md 결정 #7)

| 시작점 | 대기열 |
|---|---|
| 재생목록 [처음부터 듣기] | 그 재생목록의 항목 순서 |
| 재생목록 항목 [여기부터] | 그 재생목록 전체, **누른 문장부터** |
| 문장 탭 [전체 듣기] | 전체 문장(목록에 보이는 순서 = 최근 추가가 위) |
| 문장 카드 [듣기] | 그 문장 하나 |

모든 시작점에 같은 반복 설정이 적용된다. 문장 하나를 3회 반복하면 그 문장을 세 번 읽는다.

- [여기부터] 는 음악 앱과 같다. 1회면 누른 문장부터 **끝까지** 듣고 멈춘다. 2회 이상이면 두 번째 바퀴부터 처음부터 전체를 돈다.
- 🚫 문장 탭에서 카드 전체를 눌러 재생하는 동작은 두지 않았다(2026-09-26). [듣기]·[수정] 두 버튼과 겹쳐 부모님이 헷갈린다(기둥 4).

## 2. 반복 (A안)

- `repeat = 1..99` 또는 `0`(무한). **대기열 전체**를 그 횟수만큼 돈다. 기본 1.
- 네이티브가 센다: 마지막 항목 → 첫 항목 자동 전환(`DISCONTINUITY_REASON_AUTO_TRANSITION`)이 일어날 때마다
  `loop += 1`. `loop == repeat` 가 되는 순간의 전환 대신 **정지**하고 첫 항목으로 되돌린다.
  - 구현은 `REPEAT_MODE_ALL` 을 켜 두고 횟수를 서비스가 세는 방식이다. 대기열을 N배로 복제하지 않는다
    (100문장 × 99회 = 9,900 항목이 된다).
- 사용자가 [다음] 으로 마지막에서 첫 항목으로 넘긴 것은 **반복 횟수에 세지 않는다**(사용자 조작이다).
- 셔플이 켜져 있으면 ExoPlayer 셔플 순서를 쓴다. 한 바퀴가 끝날 때마다 새로 섞는다.

## 3. 간격을 파일에 넣는 이유

문장 사이 간격(0~5초, 기본 1초)을 **합성 파일 끝에 무음으로 붙인다**(TTS_SYSTEM.md §3).

- JS `setTimeout` 으로 쉬면: 화면이 꺼진 뒤 타이머가 늦거나 멈출 수 있다(기둥 2 위반).
- 네이티브에서 일시정지 후 재개하면: 멈춘 동안 서비스가 포그라운드에서 내려가 프로세스가 정리될 수 있다.
- 무음 파일을 별도 항목으로 끼우면: [이전]/[다음] 이 무음에 걸린다.
- → 파일 끝 무음은 **플레이어가 계속 "재생 중"** 이라 셋 다 없다. 대가는 간격을 바꾸면 무음 붙인 파일을 다시 만드는 것(원본 합성은 캐시가 살린다).

## 4. 점진 합성

재생을 누르면 **첫 문장만 합성하고 바로 재생**한다. 나머지는 JS 가 순서대로 합성해 `append` 한다.

- 합성이 재생보다 빠르다(문장당 수백 ms). 그래도 끝에 닿으면: 반복을 아직 켜지 않은 상태이므로 `ENDED` 가 되고,
  다음 항목이 붙는 순간 서비스가 이어서 재생한다.
- **대기열이 전부 붙기 전에는 `REPEAT_MODE_OFF`**, 다 붙으면 사용자 반복 설정을 적용한다.
  안 그러면 절반만 붙은 상태에서 한 바퀴가 끝난 것으로 센다.
- 셔플은 합성 순서와 무관하다. 전부 붙은 뒤 셔플을 켠다. (⚠ 그래서 셔플을 켜고 큰 목록을 재생하면 첫 바퀴의 앞부분은 원래 순서다. POLISH 후보)

## 5. JS ↔ 네이티브

JS → 네이티브(`modules/sentence-audio`):

```
setQueue(items[{ id, uri, title, subtitle }], startIndex, options{ repeat, shuffle, speed, complete })
appendItems(items)
insertItems(index, items)     // 누른 문장보다 앞의 문장들
seekToItem(id)
markQueueComplete()           // 점진 합성이 끝났다 → 반복·셔플 적용
play() · pause() · next() · previous() · seekToIndex(i) · stop()
setRepeat(n) · setShuffle(b) · setSpeed(x) · setSleepTimer(ms | 0)
getState()
```

네이티브 → JS(이벤트 `onPlayerState`):

```
{ isPlaying, index, itemId, loop, repeat, shuffle, speed, sleepAt, ended, queueLength }
```

- `itemId` 는 JS 가 넘긴 id(재생목록 항목 id 또는 문장 id)다. 강조 표시는 이 값으로 한다.
- 속도는 ExoPlayer `PlaybackParameters(speed)` 다. 프리셋의 `rate` 와 곱해진다(프리셋은 합성 속도, 이것은 재생 속도).

## 6. 슬립 타이머

- 끔 · 10 · 20 · 30 · 60분 · **이번 바퀴 끝나면**.
- 서비스의 `Handler.postDelayed` 로 센다(JS 타이머 아님, 기둥 2). 시간이 되면 일시정지.
- "이번 바퀴 끝나면" 은 다음 루프 경계에서 정지다.

## 7. 알림 · 잠금화면

- Media3 `DefaultMediaNotificationProvider` 를 쓴다. 제목 = 문장 앞 40자, 부제 = 재생목록 이름(없으면 `읽어줘`).
- 버튼: 이전 · 재생/일시정지 · 다음.
- Android 13+ 알림 권한: 미디어 세션 알림은 권한 요청 대상에서 빠진다. 권한을 묻지 않는다.
- 알림을 눌러 앱을 열면 재생 화면이 아니라 앱이 마지막에 있던 화면으로 간다(단순함).
- 앱을 최근 앱 목록에서 쓸어 지우면: 재생 중이면 계속, 일시정지면 서비스를 끝낸다.
