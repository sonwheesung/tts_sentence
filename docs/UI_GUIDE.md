## 3. 🚫 금지 목록

- 🚫 아이콘만 있는 버튼에 글자를 빼지 않는다. 재생·추가 같은 핵심 버튼은 **아이콘 + 글자**.
  (예외: 플레이어의 이전/재생/다음 3버튼은 음악 앱 관례대로 아이콘만. 대신 크게 64dp 이상 + 읽을 이름)
- 🚫 길게 누르기로만 되는 기능을 만들지 않는다. 부모님이 발견하지 못한다. 삭제·편집은 눈에 보이는 버튼으로.
- 🚫 스와이프로 삭제하지 않는다(실수로 지운다). 삭제는 확인 대화상자를 거친다.
- 🚫 12 미만 글자.
- ⚠ Android 입력창의 기본 밑줄: `underlineColorAndroid` 만으로는 안 지워졌다. 입력창 배경을 투명으로 두고 테두리·여백은 감싸는 View 가 맡는다(`app/sentence/edit.tsx` · 2026-09-26 에뮬레이터).
- 🚫 광고 자리가 재생 컨트롤을 가리거나 붙어 있지 않게 한다(오터치).

## 4. 광고 자리

- `AdSlot`(`components/ui.tsx`): 높이 50 · 회색 바탕 · 가운데 작은 글자 `광고`.
- 순서: 화면 → **광고 자리** → 간격 8 → 미니 플레이어 → 탭바(`app/(tabs)/_layout.tsx`). 광고와 재생 버튼 사이에 간격을 둔다(§3 오터치).
- 편집 화면·재생 화면에는 두지 않는다.
