# DOC_DISCIPLINE — 이 프로젝트의 문서 작업법

`C:\project\common\DOC_SYSTEM.md` 의 프로젝트판이다. 승계 출처는 LinkMemo(`C:\project\link_memo`).
규칙을 여기에 베끼지 않는다. 이 프로젝트에서 다르게 하는 것만 적는다.

- 정본은 `CLAUDE.md`(설계) 와 `docs/README.md`(색인 · 구현 현황) 둘이다.
- 시스템 문서는 `TTS_SYSTEM` · `PLAYER_SYSTEM` · `DATABASE` · `UI_GUIDE` 넷, 빌드 문서는 `BUILD` 다. 새 시스템이 생기면 README §1 에 같이 넣는다.
- 각 시스템 문서 맨 위 **§0 구현 현황**을 코드와 같이 고친다.
- 수치(반복 상한 · 간격 · 글자 크기)는 `(placeholder 날짜)` 꼬리표를 단다. 부모님 사용 후 확정한다.
- 한국어는 `common/KOREAN_WRITING.md` 를 따른다. 앱 화면 문구는 사람 검수 대상이다(§2).
